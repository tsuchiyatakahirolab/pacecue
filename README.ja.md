# PaceCue

PaceCueは、指定した終了時刻に合わせてルーティンを進めるEven G2用アプリです。現在の手順を1つずつ表示し、途中で遅れた場合は残り時間を再配分します。各手順の最低時間を計算に残し、省略可能な手順もユーザーが操作した場合だけ省略します。

## 終了時刻から手順を調整します

G2でスワイプして保存済みのルーティンや初期テンプレートを選び、表示された終了日時を確認してタップすると開始します。現在の手順を表示しているときにタップすると、その手順を完了して次へ進みます。予定より時間がかかった場合は残りの配分を調整し、最低時間を確保しても間に合わない場合は超過を表示します。

- 外出準備、仕事の準備、集中作業、就寝前などの手順を保存して再利用できます。
- 各手順に通常時間と最低時間を設定し、省略可能な手順を指定できます。
- 現在の手順、配分した時間、終了時刻までの余裕を確認できます。
- メニューから一時停止、再開、任意の手順の省略、操作の取り消しができます。
- 手順と進捗を端末内に保存し、ルーティンのテンプレートをJSONファイルで入出力できます。
- スマートフォンの画面を日本語と英語で切り替えられます。

手順の編集と終了時刻の入力はスマートフォンで行います。ルーティンごとに前回の終了時刻を記憶し、次にその時刻になる日時を提示するため、毎日の開始はG2から操作できます。終了時刻の保存がない場合は通常時間の合計と余裕時間から計算し、翌日を対象とする場合も日付を表示します。

ルーティンは手動で開始します。一時停止すると現在の手順の作業時間は止まりますが、終了時刻は変わりません。経過時間は保存した日時から計算するため、再度開くと現在時刻に基づいて表示を更新します。

## ブラウザーで試せます

Node.js 24以上とnpmを使用します。

```sh
npm install
npm run dev
```

`http://localhost:5173`を開くと、スマートフォン用の操作画面とG2の表示内容のプレビューを利用できます。G2の接続は不要です。このプレビューは実機のフォント、Bluetooth接続、スマートフォンをロックした際の動作を再現するものではありません。

Windowsでは、Node.js 24以上を導入してから`start-preview.cmd`をダブルクリックしても起動できます。初回は必要なパッケージを自動でインストールし、ブラウザーを開きます。利用中は起動したコマンド画面を開いたままにしてください。

## ビルドしてパッケージを作ります

```sh
npm run check
npm run pack
```

`check`は自動テストと本番用ビルドを実行します。`pack`はEven Hub向けの`release/pacecue-0.1.0.ehpk`を作成します。TypeScript、Vite、Even Hub SDK 0.0.16を使用し、アプリ用サーバーやAIのAPIキーは必要ありません。

SDKの要件はEven Realities App 2.2.10以上です。配布前には、実際に使用するスマートフォンとG2でパッケージ版を確認し、App 2.4での保存・再開も検証してください。確認項目と申請手順は[申請手順](docs/SUBMISSION.md)にまとめています。

## G2から操作します

| 操作 | 動作 |
| --- | --- |
| ルーティンの選択画面でスワイプします。 | 保存済みのルーティンや初期テンプレートを選びます。 |
| 選択画面でタップします。 | 表示された終了日時で開始します。 |
| 実行中の現在の手順でタップします。 | 表示中の手順を完了します。 |
| 実行中に上下にスワイプします。 | 現在の手順、次の手順、全体の時間を切り替えます。 |
| 次の手順や全体の時間でタップします。 | 手順を完了せず、現在の手順に戻ります。 |
| 完了画面でタップします。 | ルーティンの選択画面に戻ります。 |
| タップしてから長押しします。 | 一時停止・再開、任意の手順の省略、取り消しのメニューを開きます。 |
| 最上位の画面でダブルタップします。 | システムの終了確認を開きます。 |

実行中のルーティンがない場合は、G2に選択画面を表示します。メニューは[公式ガイド](https://hub.evenrealities.com/docs/build/contextual-menu)にある「タップしてから長押し」の操作で開きます。タイマーが0になっただけで、現実の行動を完了したことにはなりません。

## 利用ごとのAPI費用は発生しません

PaceCueにはアカウント、定期課金、広告、解析機能、実行時の外部通信がありません。Evenアプリの保存APIで端末内にデータを保存し、ブラウザーにもプレビューと復旧用のデータを保存します。現在の実装ではAIやサーバーの従量料金が発生せず、Even Realities側のアカウントや配布基盤の取り扱いは[プライバシー](docs/PRIVACY.md)で区別しています。

JSONの書き出し対象はルーティンのテンプレートであり、実行中の進捗や記憶した終了時刻は含みません。Even Appでファイルを保存できない場合は、「文字列を選択」からJSONをコピーして保存できます。読み込みはファイルの選択に加え、JSONを貼り付けて実行する方法にも対応しています。

## 公開と実機確認の状況

2026年11月6日時点で、自動テスト35件、TypeScriptの確認、Viteによる本番用ビルドが成功しています。ブラウザーでの日本語表示、開始、一時停止、再読み込みによる復元と、公式Simulator 0.9.5での英語・日本語の動作を確認しました。検証対象のファイル、結果と限界は[確認結果](docs/QA.md)に記録しています。

G2/R1実機での確認、Even Hubへの申請、承認、ストア公開は未完了です。GitHubの公開先は`tsuchiyatakahirolab/pacecue`を予定しており、GitHubとEven Hubの操作には各サービスへのログインが必要です。残る実機確認と申請項目は[申請手順](docs/SUBMISSION.md)にまとめています。

時間配分は入力した所要時間に基づく計算です。スマートフォンがバックグラウンドに移った際の表示はEvenアプリの動作にも依存し、再開時の時刻補正だけで停止中の表示まで保証することはできません。既存アプリとの違いは[開発方針と競合比較](docs/PRODUCT.md)で説明しています。
